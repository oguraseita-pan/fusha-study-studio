# Fuṣḥā Study Studio

Modern Standard Arabic learning hub, with grammar and private-class lessons.

Production: https://fusha-study-studio.vercel.app

## Contents
- Grammar (English / Japanese)
- Week 01 and Week 02 lessons
- Everyday conversation practice

This repository hosts static HTML files. Arabic audio playback depends on browser speech synthesis.

## Maintenance
Add future lessons under `content/`, then update `index.html` to link to them.
